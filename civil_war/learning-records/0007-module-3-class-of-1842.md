# 0007 — Module 3: The Class of 1842

Created Lesson 3 covering the Class of 1842 — "the class the gods sent." Four figures: Longstreet (ranked 54th of 56, Lee's Old War Horse, opposed Pickett's Charge), D.H. Hill (ranked 28th, scholar-soldier, married Jackson's sister), Rosecrans (ranked 5th, briefly outranked Grant, crushed at Chickamauga), and Pope (ranked 17th, braggart destroyed at Second Bull Run by Lee and Jackson).

Trick clue woven in: Longstreet was right about Pickett's Charge — Lee overruled him and later said "it's all my fault." This connects to the Longstreet-Grant friendship from Module 2.

Retrieval practice includes 3 Odd One Out warmups, 5 Core Jeopardy clues, and 3 Previously On… questions from Modules 1-2. Cross-references to all prior modules.
