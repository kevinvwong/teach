# 0004 — Expert Team Curriculum Redesign

Convened a three-expert team (Jeopardy strategist, Civil War historian, instructional designer) in parallel task agents to redesign the curriculum. Their recommendations have been fully applied.

Key changes:
- **Syllabus restructured**: 13 modules (0–12), 7 sessions. Added Module 0 (Numerical Anchors daily drill) and Module 3 (Class of 1842).
- **Lesson 1 rewritten**: Storylines now come before Meet the Cast (emotional hook first). Added Numeric Anchors table. Restructured Jeopardy practice into 4 phases (Warm-up Odd One Out → Core Jeopardy → Previously On… → Answers). Wove in 3 "trick clue" facts.
- **New retrieval practice format**: Every lesson after Module 1 includes "Previously On…" spaced questions from prior modules.

The user's goal is explicitly Jeopardy readiness. This curriculum is now optimized for that.
